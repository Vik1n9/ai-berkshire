# ai-berkshire Roadmap

## P0：近期（1-2個月）

### A股資料來源接入
- 接入 akshare、東方財富等免費資料來源
- 覆蓋 A 股財務資料、行情、龍虎榜
- 現有 Skill 無需改動，資料層擴充套件即可

## P1：中期（3-6個月）

### 報告管理前端（原「HTML 報告輸出」）
- 網頁前端查閱／篩選／追蹤報告，支援暗色模式、導航、全文搜尋
- metadata 三層合併（frontmatter → 人工標註 → 啟發式推導），md 檔仍是唯一真相
- 接上個人持倉資料，做到「持股 ↔ 報告」聯動
- **詳細施作計畫見 [報告管理前端-實施計畫.md](報告管理前端-實施計畫.md)**
- 進度：frontmatter 規範與推導工具鏈已完成（PR #14）；索引產生器與前端待施作

### 多檔深度模式
- `lite`：5分鐘速判，快速給出估值區間和核心結論
- `standard`：當前預設模式，完整多Agent研究
- `deep`：增加更多交叉驗證和歷史類比，機構級深度

### 多股橫向對比
- 支援 2-4 只股票同維度橫向對決
- 同行業公司估值對標
- 輸出對比矩陣和擇優建議

## P2：長期（6個月+）

### 測試覆蓋
- 為核心工具（financial_rigor.py 等）增加單元測試
- 為 Skill 輸出增加回歸測試
- 確保迭代不破壞已有功能

### 組合級分析
- 持倉組合健康度評估
- 行業/地域集中度分析
- 相關性風險檢測

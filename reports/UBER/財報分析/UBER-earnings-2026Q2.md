## 二、本期最重要的3個變化（≤500字）

**變化一：營收+12%失真，Bookings+24%才是真相。** 英國Mobility轉代理模式（駕駛款淨額沖營收）單季拖累營收~$1.1B、相當於總增速-8pp；Mobility帳面僅+1%但Bookings +22%、分部營業利益+28%且margin 7.6%創新高。市場用營收miss解讀為需求弱是誤讀——利潤跟Bookings走，不跟會計營收走。

**變化二：獲利含$1.6B一次性，扣非後並不便宜。** 淨利+77%/EPS +86%中，$1,618M來自股權證券重估（Delivery Hero+Aurora未實現為主，去年同期為-$17M拖累）。Non-GAAP EPS $0.81僅符合預期（部分口徑小miss 2–3%）。GAAP PE 16.6x看便宜，扣非（剔除重估＋2024年$64億遞延稅回撥基數）隱含PE ~44x——與2026-09-01深度報告結論一致。

**變化三：從回購轉向併購，資產負債表開始加槓桿。** H1回購$35億後Q2僅$5.18億，管理層明言“戰術轉向M&A，未來數月重建（回購）而非數季/年”。債務+ $22億＋€140億過橋承諾，對應Delivery Hero $148億股權對價＋2028規劃、2029遷單一Uber棧。若整合不及預期，輕資產高FCF敘事將被稀釋。

## 四、附註中的隱藏資訊

- [x] **股權重估**：$1,618M利得（未實現$1,727M市價＋非市價-$312M＋已實現$203M），主要Delivery Hero+Aurora。佔稅前利潤~2/3，不可持續，明年若無此類收益EPS同比承壓。
- [x] **UK代理模式**：駕駛款從成本沖營收，Mobility營收margin -500bp YoY。好處是利潤率虛增，壞處是營收增速未來4季仍不可比。
- [x] **或有負債/債務**：Term Loan $3.0B（SOFR+0.825%）已提$2.0B＋€14B過橋；公允債務$12.9B。併購交割前利息與承諾費先行。
- [x] **會計政策**：Adj. EBITDA降級為過渡指標，轉向Non-GAAP OI——與分部OI銜接，透明度提升，加分。
- [x] **集中度**：AV供給依賴Waymo/Aurora/Baidu等外部技術，無自研車；需求端MAPC 2.08億為議價籌碼。
- [x] **異常檢測**：應收增速未超營收（未披露惡化）；存貨N/A；OCF>淨利（扣非後更優）；資本化開支未增；非經常收益佔比高（已標紅）。

## 六、結論

1. **超預期/符合/低於？——符合預期偏多。** Bookings、Adj. EBITDA、Non-GAAP OI超；營收小miss係會計變更＋共識偏高（$14.24B vs $14.19B）；Q3指引（Bookings $582.5–602.5億、Non-GAAP EPS $0.84–0.88）略低於$0.91共識，管理層一貫保守。
2. **對論文影響：強化。** 核心（密度→利潤→現金）更強，一次性利得與加槓桿是雜音而非主線。
3. **下一個催化劑**：Delivery Hero歐盟審查進展；Q3 Bookings是否連5季20%+；AV 15城落地；保險再投入能否轉化為美國Mobility加速。
4. **持有該加/持/減？持有。** 空倉等$65–70（P/FCF<13x）分批；持倉$95–100減半；紅線（僱員化立法＋Freight虧損擴大＋Uber One退訂）未觸發。
